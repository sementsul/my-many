# MyMany — карта проекта (project-notes)

Статический сайт **«Арбитражная база цепочек обмена»** на домене **my-many.ru** (Cloudflare → GitHub Pages).
**Проект RateScout по арбитражу.** (Раньше был CoinGecko-монитор рынка — с 2026-09-06 полностью переделан.)

## Зачем и связь с ratescout
- **ratescout.ru** = «где выгодно обменять» (обменники BestChange, направления, AML) + страница цепочек `/tsepochki/`.
- **my-many.ru** = «огромная база цепочек для заработка на обмене» (арбитраж): монитор цепочек, страница каждой
  цепочки с калькулятором, страницы входа по стартовой валюте. Смысловая перелинковка на ratescout (обмен/курсы/валюта).
- Интерфейс/футер — как у ratescout (его `styles.css`, DOS-тема). В футере — «проект RateScout по арбитражу».

## Данные (важно!)
- Источник цепочек — **направленные курсы BestChange** = `rates.json` (42k пар `A>B` с rate/count/reserve).
  🔴 В ratescout он **в .gitignore** (генерится в CI) → ratescout ПУБЛИКУЕТ его в свой dist: **`https://ratescout.ru/rates.json`**.
  MyMany тянет оттуда. `history.json`/`currencies.json` — из raw-GitHub ratescout (закоммичены).
- Фолбэк — кэш `data/*.json` (rates/history в .gitignore — крупные; `currencies.json` можно держать в репо).
- 🔴 Порядок деплоя: сначала ratescout публикует rates.json, потом собирается MyMany.

## Что где
- `build.py` — генератор. `compute_shards()` строит граф ликвидных лег (≥2 обменников, резерв>0, санити по USDT-курсу
  0.66..1.5×) и считает выгодные цепочки 2/3/4 звена, раскладывая по **стартовой валюте** (шарды). Рендерит:
  - `/` — монитор цепочек (топ-800 встроен, фильтр по стартовой валюте, режимы 2/3/4, сорт доходность/риск, мини-бары,
    «показать ещё»); статы (сколько цепочек/валют/узлов, лучшая).
  - `/c/` — единая страница цепочки, клиентский рендер по `?s=<slug>&i=<index>` из шарда: пошаговая конверсия
    (курс на каждом шаге, running-сумма) + **калькулятор** (вводишь сумму — видишь итог и прибыль). Курсы — ПОЛНЫЙ float
    (не округлять: крипта→фиат теряет точность, калькулятор врёт).
  - `/valuta/<slug>/` — SSR-страница «арбитраж с <валюты>»: все её цепочки таблицей + перелинковка на ratescout `/valuta/<slug>/`.
  - `data/chains/<slug>.json` — шард базы (компактные ключи m/n/l/p/r/c).
  - `data/chain-history.json` (+`data/chist/<slug>.json`) — история доходности цепочек (пишется ВПЕРЁД: точка на обновление данных, топ-800, ~168 точек; персист фетчем прошлого файла с живого сайта). График на `/c/` над калькулятором с тултипом.
- Пороги: `SHARD_CAP=200` цепочек/валюта, `TOP_CAP=800` в монитор. `MINC=2`. Дедуп по набору тикеров (варианты USDT не плодим).

## i18n (RU/EN) — как у ratescout
- Константы: `LANGS=["ru","en"]`, `PREF={"ru":"","en":"/en"}`. **RU в корне** (`/`), **EN в `/en/`**.
- Все шаблоны принимают `lang`; строки — через хелпер `L(lang, ru, en)` (inline, как у ratescout). Тексты внутри JS
  (монитор `HOME_JS`, калькулятор/график `DETAIL_JS`) вынесены в объект `LBL` и инжектятся `json.dumps` — своя копия на язык.
- Ссылки на ratescout — через `rs(lang, path)` (EN-страницы ratescout лежат в `/en/…`). Внутренние ссылки монитора на
  `/c/` строятся в JS как `LBL.cpref + "/c/"` → в EN даёт `/en/c/`.
- В `<head>`: `hreflang` ru/en/x-default, `og:locale`, `<html lang>`. Переключатель языка (🌐 EN/RU) — последним пунктом меню,
  ведёт на тот же путь в другой версии.
- **Общие данные** (`data/chains`, `data/chist`, `chain-history.json`) — языконезависимы, лежат в корне и шарятся обеими
  версиями (детальная страница фетчит `/data/…` абсолютным путём — работает и из `/en/`).
- `sitemap.xml` — RU+EN URL с `xhtml:link` alternate (ru/en/x-default). 404: корневой `/404.html` (его отдаёт Pages) + `/en/404.html`.

## Запуск / сборка
- `python3 build.py` → `dist/`. ~15с. Локально rates.json берёт из кэша (боевой ratescout.ru/rates.json появится после его деплоя).

## Деплой
- Репо **github.com/sementsul/my-many**, пуш по SSH ([[github-ssh-container]]).
- **GitHub Actions:** `deploy.yml` — cron `*/15` (+сдвиг), пуш и dispatch → Pages. `keepalive.yml` — недельный PAT-коммит
  (чтобы scheduled-воркфлоу не уснул за 60 дней). 🔴 нужен секрет `GH_PAT`.
- **Cloudflare:** DNS my-many.ru → Pages, SSL Full, оранжевое облако.
  🔴 Переводим на ПРЯМОЙ GitHub Pages (серое облако/A-записи 185.199.108–111.153) — Cloudflare-прокси режут в РФ.
- **Защита ветки:** `protect.yml` (workflow_dispatch) через `GH_PAT` включает на `main` запрет force-push/удаления + enforce_admins, БЕЗ required PR/checks (иначе прямой push keepalive/deploy отвалится и крон умрёт).
- **Аналитика/индексация (СОХРАНЕНЫ):** Я.Метрика **111586112** + GA **G-PPN27D6JXS**; Яндекс-тег `d5dd2e5c5d4ee324`.
