# MyMany — карта проекта (project-notes)

Отдельный статический сайт **«Монитор крипторынка»** на домене **my-many.ru** (домен уже на Cloudflare).

## Зачем и чем отличается от ratescout
- **ratescout.ru** = «где выгодно **обменять**» (обменники BestChange, направления, AML).
- **my-many.ru** = «что происходит на **рынке**» (обзор цен/капитализации/настроений) → ведёт на ratescout как на сервис обмена.
- 🔴 Разный интент — чтобы НЕ было каннибализации/дубля с ratescout (`/lidery-rynka/`, `/nastroeniya/` и т.п.).
  Тексты уникальные, не копия. Сателлит «просто ради ссылки» НЕ делаем (риск PBN-штрафа).

## Что где
- `build.py` — генератор: тянет CoinGecko (`/global`, `/coins/markets`) + alternative.me (индекс страха/жадности),
  рендерит `dist/index.html` (SSR, данные вшиты для индексации) + sitemap/robots/CNAME. Фолбэк — кэш `data/*.json`.
- `dist/` — сборка (в .gitignore; публикуется в Pages).
- `data/` — кэш последних ответов API (фолбэк, если сеть недоступна на сборке).

## Запуск / сборка
- `python3 build.py` → `dist/`. Данные живые (CoinGecko доступен из контейнера, проверено).

## Деплой (СДЕЛАНО)
- Репо **github.com/sementsul/my-many**, пуш по SSH ([[github-ssh-container]]).
- **GitHub Actions:** `deploy.yml` — ежечасная пересборка + публикация в Pages; `keepalive.yml` — недельный коммит под `GH_PAT`
  (чтобы крон не заснул за 60 дней). Экшены на checkout@v5/setup-python@v6.
- **Cloudflare:** DNS my-many.ru → GitHub Pages, SSL Full, оранжевое облако (чтобы CF-аналитика продолжала видеть трафик).
- **Аналитика:** Яндекс.Метрика 111586112 + GA G-PPN27D6JXS (те же, что ratescout; my-many.ru добавлен в домены счётчика).
- **Индексация:** Яндекс.Вебмастер (тег `d5dd2e5c5d4ee324`) + Google Search Console (через GA) + sitemap — подтверждено.
